# Contributing

Thank you for helping improve KMoon Web Analyzer.

## Forking and modifying

1. Fork the repository.
2. Create a branch for your feature or fix.
3. Update the extension code and documentation.
4. Run the validation tests locally.
5. Submit a pull request with a summary of the change.

## Local validation

```bash
npm run build
npm test
```

## Reporting issues

Please use the GitHub issue tracker to report bugs, feature requests, or security concerns.
