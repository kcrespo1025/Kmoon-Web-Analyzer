# Changelog

## 1.2.0

- Added extension inventory, authorized one-off page code executor, inspector, logs search/export, history, storage inspection, source reference list, and a shortcut workspace.
- Added page snapshot downloads and limited security-header/third-party indicators.
- Corrected official repository identity to `kcrespo1025/Kmoon-Web-Analyzer`.
- Documented advanced features that are not implemented and clarified metadata verification limitations.

## 1.1.0

- Replaced the side panel with an on-page floating analyzer.
- Added a draggable, resizable overlay with left-side tabs and persistent Kmoon1025 copyright credit.
- Start monitoring only after the user clicks the in-page control.
- Removed always-on content script injection to reduce page overhead.
- Batched activity logging and DOM mutation summaries to reduce lag.

## 1.0.0

- Initial KMoon Web Analyzer extension release.
- Added local-only activity monitoring.
- Added network and JavaScript logging.
- Added DOM and navigation tracking.
- Added history, settings, and security verification UI.
- Added documentation and privacy protections.
